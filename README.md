# 자정 주파수 — 공개 플레이테스트

폭우가 쏟아지는 밤, 산속 폐방송국에서 실종된 동생 하윤을 찾는 한국어 1인칭 포인트앤클릭 미스터리 게임입니다.

## 플레이

**https://altakori.github.io/undecided-character-playtest/**

- 데스크톱과 모바일 브라우저 지원
- 키보드·마우스·터치 지원
- 진행 상황과 확인한 엔딩은 현재 브라우저에 자동 저장
- 공포 이미지, 짧은 비명과 음향 연출 포함
- 브라우저 정책상 첫 클릭 이후 음향이 시작될 수 있음

## 테스트 피드백

버그, 잘린 UI, 이해하기 어려운 퍼즐, 음량 문제, 재미가 떨어지는 구간을 발견하면 [GitHub Issues](https://github.com/altakori/undecided-character-playtest/issues)에 남겨 주세요.

가능하면 다음 정보를 포함해 주세요.

1. 사용 기기와 브라우저
2. 문제가 발생한 장소 또는 퍼즐
3. 재현 순서
4. 예상한 결과와 실제 결과
5. 스크린샷

## 공개 범위

이 저장소에는 플레이테스트용 정적 빌드만 들어 있습니다. 개발 저장소의 브랜치와 작업 기록은 포함하지 않습니다.

게임에 포함된 외부 음향의 출처와 라이선스는 [THIRD_PARTY_ASSETS.md](THIRD_PARTY_ASSETS.md)를 참고하세요. 별도 라이선스가 명시되지 않은 게임 이미지·문구·배포물의 권리는 저장소 소유자에게 있습니다.
